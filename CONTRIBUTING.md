# Contributing

This is a build-free static site. `ARCHITECTURE.md` explains the runtime design; this file is the day-to-day workflow.

## Setup

Requires Node 22+.

```bash
npm ci
npm run serve      # http://127.0.0.1:4173/
npm test           # Playwright: Chromium, Firefox, WebKit
```

Python is only needed if you regenerate reader previews.

## Before every commit

```bash
npm run check
npm test
```

`npm run check` runs version, global-name, content, site-integrity, public-URL, sitemap, HTML, CSS, partial, precache, PDF metadata, and PDF budget checks. The site-integrity check (`scripts/check-site.mjs`) is the cross-platform source of truth for catalog/assets/page links.

CI additionally runs:

- `pwsh -NoProfile -File scripts/check-site.ps1` as a second opinion
- Lighthouse on the home and grown-ups pages
- the full Playwright suite in Chromium, Firefox, and WebKit
- `npm run check:live` after a successful GitHub Pages deployment

The live smoke test can also target a local server:

```bash
npm run check:live -- http://127.0.0.1:4173
```

## Common changes

### Change interface copy or add a translation

- Static English text: add the exact English sentence as a key in `data/translations.js`, then verify it in Spanish.
- Text generated by JavaScript: update the English/Spanish pair at the call site and any accessible label.
- Safety-card draft translations live inside the `.spanish-copy` blocks in `index.html`; they are intentionally marked as draft.

### Add or replace a printable PDF

1. Put the print-quality PDF in `assets/pdfs/` and its thumbnail in `assets/graphics/`.
2. Add an entry to `window.BOBBER_RESOURCES` in `data/resources.js` (keep filenames exact).
3. Add the Spanish title to `BOBBER_RESOURCE_TITLES_ES`.
4. Run `npm run update:pdf-meta`.
5. If the PDF is large, create a preview (below).
6. Bump the version and test.

### Generate a lightweight reader preview

The reader uses raster previews for the largest files so the first page opens quickly. Print PDFs stay untouched at 300 DPI with their tags.

```bash
python3 -m pip install pypdfium2 img2pdf pillow
python3 scripts/generate-preview-pdf.py \
  "assets/pdfs/Foo.pdf" "assets/pdfs/web/Foo-web.pdf" --dpi 120 --quality 72
npm run update:pdf-meta
```

To regenerate the current twelve previews on macOS/Linux:

```bash
while IFS= read -r name; do
  python3 scripts/generate-preview-pdf.py "assets/pdfs/$name" "assets/pdfs/web/${name%.pdf}-web.pdf" --dpi 120 --quality 72
done < scripts/reader-previews.txt
```

On Windows PowerShell:

```powershell
Get-Content scripts/reader-previews.txt | ForEach-Object {
  python scripts/generate-preview-pdf.py "assets/pdfs/$_" "assets/pdfs/web/$($_.Replace('.pdf','-web.pdf'))" --dpi 120 --quality 72
}
```

### Change tips, quiz questions, or pal cards

Edit `data/content.js` only. Run `npm run check:content`. Every quiz question must have exactly one correct option.

### Add a top-level script name

The classic scripts share one global scope. Run `npm run check:globals` after adding a top-level `const`, `let`, `function`, or `class` to `main.js`, `pdf-reader.js`, or a browser data file. Prefer names scoped inside a function unless the page needs them globally.

### Change CSS

Read the stylesheet map at the top of `styles.css`. Keep the existing order; later sections intentionally refine earlier passes. The mobile navigation structure is owned by the `max-width:1200px` block, while the `max-width:640px` block adjusts spacing.

Core dark surfaces and the fixed print palette are defined as tokens at the top of the file. Use those tokens for theme/print work; one-off illustration and state colors remain literal on purpose.

### Change PWA behavior

- `sw.js` owns cache names and fetch strategies.
- `precache.json` is generated; never edit it by hand.
- PDFs and the classroom ZIP are intentionally excluded.
- Test offline root, `grown-ups.html?lang=es`, a thumbnail with `&` in its filename, and the update banner.
- Bump the version so clients install a fresh shell.

### Bump the site version

```bash
npm run bump:version -- 20261121a
```

Use the next `YYYYMMDDx` value. This updates both pages, the classroom-pack link, `sitemap.xml`, and `precache.json`, then verifies consistency. Run `npm run check` afterwards.

### Change the public URL

`site.config.json` is the source of truth. Do not search-and-replace URLs by hand:

```bash
npm run update:site-url -- https://example.gov/bobber
npm run bump:version -- 20261121a
npm run check
```

The URL update rewrites canonical/OG/hreflang metadata, robots, poster text, README links, sitemap, QR codes, and the classroom pack. The version bump refreshes client caches for the regenerated QR/pack assets.

## Code conventions

- Prefer `textContent` and DOM creation over `innerHTML` for anything data-driven.
- Keep public-safety copy bilingual and reviewable; do not bury sentences in event handlers if they can live in `data/content.js` or `translations.js`.
- Use named constants for timing, sizes, and cache limits.
- Update accessible names whenever visible labels change (language toggle, dialogs, external links, print controls).
- Keep `aria-*`, focus movement, and keyboard behavior covered by a test when changing dialogs or controls.
- Do not add a build step or third-party runtime dependency without discussing deployment constraints.

## Testing map

All suites run in Chromium, Firefox, and WebKit.

- Home/language/theme: `tests/home.spec.js`
- Library, reader, filters, navigation: `tests/library.spec.js`
- Game/certificate: `tests/game.spec.js`
- Offline/service worker: `tests/offline.spec.js`
- Axe/print/forced colors: `tests/accessibility.spec.js`
- Production/deployed smoke: `scripts/check-live.mjs`

## Review status

Spanish interface/safety copy, Section 508, Public Affairs, and official USACE approval remain external reviews. See `CONTENT_REVIEW.md` and `ARCHITECTURE.md`.
